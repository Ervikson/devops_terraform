# Архитектура итогового проекта

## Компоненты
1. **VPC + подсети** – изолированная сеть `final-vpc` и две подсети /24 в зонах `ru-central1-a` и `ru-central1-b`.
2. **Группа безопасности** – разрешены входящие TCP 22/80/443, исходящий трафик не ограничен.
3. **Управляемая БД MySQL** – кластер `final-mysql` c БД `appdb` и пользователем `app`.
4. **LockBox** – секрет `final-mysql-secret` содержит пароль пользователя `app`.
5. **Container Registry** – хранит образ web-приложения `final-app`.
6. **ВМ приложения** – одна или несколько ВМ с cloud-init и Docker.

## Потоки
- При развёртывании Terraform создаёт сеть, БД, секрет и регистр.
- Cloud-init ставит Docker/Compose, после чего оператор выполняет `docker login` и `docker run`/`compose up` с образа из YCR.
- Приложение получает строку подключения к MySQL через переменные окружения, пароль подтягивается из LockBox API.

## Хранение состояния
Terraform backend использует Object Storage + DynamoDB-совместимую таблицу для блокировок.

## Доступность
- Веб-приложение доступно по публичным IP ВМ или через внешний DNS, если настроен.
- Потенциально можно добавить Network Load Balancer поверх ВМ.
